# Sonata App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the indigo "S" with the Midnight baton-and-followers icon in the Dock and Finder, the Tauri icon set, the menu bar, the DMG and the About screen.

**Architecture:** `app/app-icon.svg` is the single source. `app/app-icon.png` is rendered from it, and `npx tauri icon` turns the PNG into `app/src-tauri/icons/`. The menu-bar icon stays a 36×36 alpha grid in `tray.rs`. The DMG reuses the app's `icon.icns` instead of re-padding the PNG.

**Tech Stack:** SVG, `rsvg-convert` and ImageMagick (one-off rendering, not project dependencies), Tauri 2 CLI, Rust (tray tests), POSIX sh (DMG script).

**Spec:** `docs/superpowers/specs/2026-11-17-app-icon-design.md`

**Before Task 1:** create a branch `app-icon` from `master`.

## Global Constraints

- Canvas is 1024×1024 with an 824×824 body inset 100px. The body uses the continuous-corner curve from `app/scripts/volume-icon.swift` (rect 100…924, radius 220).
- Background gradient is `#33307f` → `#12102e` (top to bottom), with a white radial spotlight at about 16% toward the upper right.
- Bots: amber `#fbbf24` (largest, nearest the tip), green `#34d399`, pink `#fb7185` (smallest, farthest). Baton is white. Trail is white dots at about 32% opacity.
- Reference art: `.superpowers/brainstorm/70353-1794930040/icon/reference-midnight.svg` and `reference-mono.svg` (local, gitignored).
- The menu-bar icon is 36×36, black only, with a transparent border. It shows the baton and three dots, without the trail.

## Review Focus

- **macOS icon cache.** After rebuilding, the Dock and Finder may keep showing the old icon. Run `killall Dock Finder` before judging the result (Task 3, step 4).
- **Dock size.** `tauri icon` must keep the transparent padding. The corner pixel of the largest icns image must be transparent (Task 1, step 6).
- **16px legibility in Finder list view.** Look at `icon_16x16.png` extracted from the icns (Task 1, step 6).
- **DMG padded twice.** The volume icon must be byte-identical to the app's icns (Task 3, step 4).
- **Gradient banding at 1024px.** Inspect the rendered PNG at 100% zoom (Task 1, step 4).

### Task 1: New icon source and generated icon set

**Files:**
- Modify: `app/app-icon.svg`, `app/app-icon.png`
- Regenerate: `app/src-tauri/icons/**`
- Add: `docs/superpowers/specs/2026-11-17-app-icon-design.md`, this plan

**Interfaces:**
- Produces: `app/src-tauri/icons/icon.icns` (used by Task 3), the final mark geometry (used by Task 2 via `reference-mono.svg`)

- [ ] **Step 1: Port the body shape.** Translate `body(_ side:)` from `app/scripts/volume-icon.swift` into an SVG path string for side 1024: four corners, each made of three cubic curves scaled by radius 220 through the `at()` mapping, joined by straight edges. The shape is symmetric, so CoreGraphics' y-up versus SVG's y-down doesn't matter. Do this before Task 3 deletes that file.
- [ ] **Step 2: Write `app/app-icon.svg`.** Start from `reference-midnight.svg`. Replace both `<rect … rx="185">` elements (body fill and spotlight) with the ported path, and keep the gradient, spotlight, body shadow, mark shadow and mark paths. No external references, fonts or images.
- [ ] **Step 3: Render.** Run `rsvg-convert -w 1024 -h 1024 app-icon.svg -o app-icon.png` from `app/`.
- [ ] **Step 4: Verify the PNG.** Running `magick app-icon.png -format '%wx%h %[pixel:p{40,40}] %[fx:p{512,512}.a]\n' info:` should print `1024x1024 srgba(0,0,0,0) 1` (padding transparent, body opaque). Open it at 100% and compare with `reference-midnight.png`. If the dark gradient shows bands, add a low-opacity noise layer (an `feTurbulence` filter at about 3% opacity over the body) and re-render.
- [ ] **Step 5: Regenerate the icon set.** Run `npx tauri icon app-icon.png` from `app/`. Expected: `git status --short src-tauri/icons` lists only modified (`M`) files and no deletions.
- [ ] **Step 6: Check sizes.** Run `iconutil -c iconset -o "$TMPDIR/sonata.iconset" src-tauri/icons/icon.icns`. Then `magick "$TMPDIR/sonata.iconset/icon_512x512@2x.png" -format '%[pixel:p{20,20}]\n' info:` should print `srgba(0,0,0,0)`. Look at `icon_16x16.png` and `icon_32x32.png`: the baton and three dots must be distinguishable.
- [ ] **Step 7: Commit.**

```bash
git add app/app-icon.svg app/app-icon.png app/src-tauri/icons docs/superpowers
git commit -m "Replace the app icon with the Midnight baton"
```

### Task 2: Menu-bar template icon

**Files:**
- Modify: `app/src-tauri/src/tray.rs:25-62` (`ICON_ROWS` only)
- Test: the existing tests in `app/src-tauri/src/tray.rs` (`the_icon_is_a_36_by_36_black_template_shaded_as_its_rows_say`, `the_mark_has_soft_edges_and_clears_the_border`)

**Interfaces:**
- Consumes: `reference-mono.svg` (Task 1's mark, one color)
- Produces: `ICON_ROWS: [&str; 36]`, with each row 36 chars, `.` for alpha 0, otherwise one hex digit `round(alpha / 17)`

- [ ] **Step 1: Prepare the glyph.** Copy `reference-mono.svg` to the scratchpad and delete the dashed trail path (the one with `stroke-dasharray`). Refit the remaining baton and dots so they sit inside 32×32, centered, leaving at least a 2px transparent border at 36px.
- [ ] **Step 2: Rasterize and quantize.** Use a one-off script (not committed) to render it at 36×36 and turn each pixel's alpha into `.`/`1`–`f` as above. Paste the 36 rows over `ICON_ROWS`.
- [ ] **Step 3: Eyeball it.** Render the rows back to a PNG at 8× and at 18pt on a light (`#ececee`) and a dark (`#2a2a2d`) strip. Baton, grip and three dots should all be distinguishable.
- [ ] **Step 4: Run the tray tests.** Run `cargo test -p sonata-app tray` from `app/src-tauri`. Expected: 3 passed.
- [ ] **Step 5: Commit.**

```bash
git add app/src-tauri/src/tray.rs
git commit -m "Draw the baton in the menu bar"
```
